# PB3 Productions Static Site

Static GitHub Pages build for PB3 Productions, adapted from the supplied PB3 HTML content.

## Files

- `index.html` — PB3 single-page site structure and media/content references
- `styles.css` — PB3 visual system, responsive layout, reel styling, form styling
- `script.js` — mobile nav, audio toggle, service tooltips, smooth scroll, GSAP scroll effects
- `vercel.json` — optional Vercel static routing
- `robots.txt` — crawl allowance
- `404.html` — static fallback

## Notes

- The site uses the PB3 logo, hero video, audio track, reel clips, camera image, and footer artwork from the supplied HTML.
- The contact form still points to the placeholder Formspree endpoint: `https://formspree.io/f/YOUR_FORM_ID`.
- The phone number is still the placeholder number from the supplied HTML: `+15551234567`.
- GitHub Pages can serve this directly from the repository root.
