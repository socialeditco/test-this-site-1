# PB3 Productions / CREVIXA-Structure Hybrid

Static GitHub Pages build that keeps the CREVIXA-inspired page structure while swapping the brand layer to PB3 Productions.

## What this version does

- Keeps the CREVIXA-style architecture: loader, split-screen menu, fixed editorial nav, circular hero/showreel, archive-style work section, split editorial sections, contact block, and footer.
- Uses PB3 Productions copy, logo, hero video, audio track, reel clips, camera image, service language, contact copy, and footer artwork from the supplied PB3 HTML.
- Adds GSAP scroll behavior for hero parallax, marquee movement, and the horizontal reel on desktop.

## Files

- `index.html` — CREVIXA-style structure with PB3 content/media
- `styles.css` — CREVIXA-inspired layout and PB3 visual system
- `script.js` — split menu, sound toggle, tooltips, smooth scroll, reveal states, and GSAP reel behavior
- `vercel.json` — optional Vercel static routing
- `robots.txt` — crawl allowance
- `404.html` — static fallback

## Notes

- The contact form still points to the placeholder Formspree endpoint: `https://formspree.io/f/YOUR_FORM_ID`.
- Social links are placeholders until final PB3 destinations are available.
- GitHub Pages can serve this directly from the repository root.
