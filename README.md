# CREVIXA Static Site Recreation

A lightweight static recreation of the CREVIXA-style portfolio site, prepared for direct deployment on Vercel.

## Files

- `index.html` — full single-page site structure
- `styles.css` — visual system, layout, responsive styling, animation states
- `script.js` — menu overlay, scroll/header behavior, gallery interactions
- `vercel.json` — static routing and clean URLs
- `robots.txt` — crawl allowance

## Deploy on Vercel

Use the repo as a static site. No framework preset or build command is required.

## Notes

- The recreation uses external public media asset URLs from the captured CREVIXA export so the repo stays lightweight.
- Original Google Tag Manager code was intentionally not included.
- No font binaries were added; the typography uses safe system fallbacks.
